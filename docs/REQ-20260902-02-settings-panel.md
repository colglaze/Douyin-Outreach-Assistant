# REQ-20260902-02 — 设置面板（配置中心 UI）

> 关联：REQ-20260902-01（功能 4 私信模板 / 功能 5 AI 润色依赖本需求才能实际可用）、PRD.md。

## 1. 背景

V0.3 交付后发现缺口：`AppSettings`（品牌/产品/联系方式/AI 配置）已有存储层
（`storage/settings.ts`），但面板没有配置入口。导致：

- 模板渲染后 `{{brand}}` `{{product}}` `{{wechat}}` `{{contact}}` `{{category}}` 全部为空串；
- AI 润色永远处于"未配置"降级状态，用户无法开启。

这是对 REQ-20260902-01 功能 4/5 的**支撑性补全**，不扩大产品边界。

## 2. 纳入范围

| # | 功能 | 验收标准 |
|---|------|----------|
| 1 | 面板头部增加设置入口 | 点击后切换到设置视图，可返回主视图 |
| 2 | 品牌信息表单 | 品牌名称/品牌简介/产品名称/默认联系人/微信号/默认达人类型，可编辑保存 |
| 3 | 默认模板选择 | 下拉选择内置模板，保存后作为面板初始选中项 |
| 4 | AI 配置表单 | 启用开关/接口地址/Key（password 输入）/模型/语气，可编辑保存 |
| 5 | 保存生效 | 保存后 toast 提示，主视图模板内容立即用新变量重新渲染 |

## 3. 明确不做

- 模板内容的新增/编辑/删除（属 V1.0 模板管理）
- 云端同步配置（属 Phase 3）
- 表单校验规则引擎（仅做空值容忍，Key 明文存本地已有 PRD 风险说明）

## 4. 验收方式

`tsc --noEmit` 通过；`npm run build` 成功；设置保存后 `{{brand}}` 等变量在模板中正确替换。
