# REQ-20260929-03 — 私信自由编辑与自定义模板

## 目标

达人主页可直接写完整私信，也可选内置或自定义模板填入后任意改写。面板刷新、状态更新及 AI 润色不丢失当前达人的草稿。

## 范围与验收

- 模板选择含“自由编辑”；只有用户明确切换模板才覆盖编辑框。切到自由编辑保留文字；不同达人各自保留当前页草稿。
- 用户能从编辑框保存新模板、修改或删除自定义模板；内置模板不可改删。模板存本地设置，模板正文保留变量占位符；保存模板不更改已编辑草稿。
- 连刷按商务、交友模式分别选择“自由文案”或“模板”，从本地设置读取，发送前替换已支持的变量。旧设置迁移保持原有文案来源。
- 空内容、无效模板在启动连刷前阻止；删除正在使用的模板时回退到对应内置模板。
- 私信仍沿用既有填入、发送开关、筛选和发送上限。

## 非范围

- 云端模板同步、多人共享、定时发送及新增变量。
