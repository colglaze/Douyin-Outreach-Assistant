# REQ-20260929-05 — 持续连刷与私信

> 用户确认（2026-09-29）：持续浏览并自动私信，直到手动停止。

## 范围

- 推荐页面板提供两个明确入口：原有限量连刷，以及本次持续连刷。每次运行由用户点击启动；持续模式仅在当前标签页的本次会话内续跑。
- 持续模式不因发送条数或交友模式已访问 50 个主页而结束；面板显示已访问、已跳过、已发送，并提供显眼的停止按钮。
- 停止后不再进入下一位达人；若停止发生在私信打开或填入期间，发送前再次检查状态，避免继续自动发送。
- 保留自动发送开关、已联系去重、交友筛选、连续失败停止、页面异常停止、当前标签页会话过期及关闭标签页即结束。
- 为避免长时间运行使 `sessionStorage` 越来越大，只保留最近 1000 个已访问链接用于页面去重，同时保持累计访问计数；达人库去重继续防止重复发送。
- 旧会话按限量模式恢复；限量模式默认发送上限仍为 10。

## 非范围

- 定时启动、浏览器重启后自动恢复、验证码或平台限制处理、跨账号并发发送。

## 验收

- 限量模式达到上限正常结束；持续模式超过原上限后仍可继续，且没有预设发送总数。
- 交友模式持续运行超过 50 个已访问主页仍继续筛选。
- 手动停止后不再触发新的自动发送；连续失败和页面异常仍停止并显示原因。
- `npm test`、`npm run typecheck`、`npm run build` 通过；真实登录态发送链路由用户复测。
