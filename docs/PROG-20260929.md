## V0.10.1 持续连刷私信填入失败修复（最新）

- 用户确认持续连刷面板显示“私信填入失败”。公开达人页核对：私信编辑器仍可定位，但内部文本为 `.ace-line` 多行结构；未发送测试消息，草稿已清空。
- 写入后改查当前可见编辑器，避免原节点重绘造成误判；首次写入不完整时在当前编辑器尝试一次替代方法。仍无法完整填入则停止连刷、保留聊天窗口，不自动发送或跳转下一位。
- 本地验证：编辑器替换与多行回退测试通过；`npm test` 20 项通过，`npm run typecheck` 通过，`npm run build` 产出 v0.10.1 用户脚本。真实 Tampermonkey 登录态连刷仍需用户复测。

## V0.10.0 持续连刷

- 推荐页面板把启动入口拆为限量、持续两种；模式按本次运行写入当前标签页会话，旧会话按限量恢复。
- 持续模式取消发送总数、交友模式 50 主页数和“8 条无新作者视频”结束条件；下一条控件连续失效、连续发送失败或页面异常仍停止。
- 停止按钮在私信打开、填入与发送前的等待阶段生效；若发送请求已经提交，记录最后一条后保持停止，不进入下一个作者。
- 已访问链接只存最近 1000 条并保留累计访问数，长期运行不会无限增大 sessionStorage。已联系达人仍由达人库去重。
- 本地验证：`npm test` 18 项通过、`npm run typecheck` 通过，`npm run build` 产出 v0.10.0 用户脚本。登录态真实连刷仍需用户浏览器复测。

## V0.9.0 多模型接入

- 保留原有自定义 OpenAI 兼容端点；增加 OpenAI、DeepSeek、LongCat 快捷配置。切换提供商时清空旧 API Key，避免向新端点发送旧密钥。
- DeepSeek 预设为 `deepseek-flash`，同一配置可用于文字润色与封面文字提取；LongCat 预设为官方文字模型 `LongCat-2.0`，封面图像请求直接跳过并展示原因。
- 两个预设的短请求关闭思考模式，以保障短输出额度留给最终文案或识别结果；自定义端点保持原请求格式。
- 本地验证：`npm test` 15 项通过、`npm run typecheck` 通过，`npm run build` 产出 v0.9.0 用户脚本。未持有用户的服务商 API Key，因此未发起真实付费请求。

## V0.8.0 私信编辑与自定义模板

- 达人主页可自由编辑或选模板填充后改写；按达人和商务/交友模式保存当前页草稿，面板刷新不重套模板。手写文案里的已知变量在填入前展开，未知占位符原样保留。
- 编辑框可保存、更新、删除本地自定义模板；内置模板只读，删除被连刷引用的模板会回退到对应内置模板。
- 商务与交友连刷可分别选自由文案或模板。旧设置中非空商务自定义文案继续作为来源；空文案继续使用默认模板。空来源或无效模板在启动前阻止。
- 设置即时保存自动发送开关时不再刷新整张设置表单，避免清掉其他尚未保存的输入。
- 本地验证：`npm test` 13 项通过、`npm run typecheck` 通过，`npm run build` 产出 v0.8.0 用户脚本。达人主页 Tampermonkey 交互与真实私信仍需在用户的已登录浏览器复测。

## V0.7.0 作品线索识别
