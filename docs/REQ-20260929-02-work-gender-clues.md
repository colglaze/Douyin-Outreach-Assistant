# REQ-20260929-02 — 作品性别线索识别

> 用户需求（2026-09-29）：根据作品识别性别；补充选择“文字和画面/声音线索结合”。

## 范围

- 达人主页增加“识别作品线索”按钮，读取当前主页最近公开作品的标题/文案与封面。
- 自动检查作品文字中的明确第一人称性别自述；用户可选填作品台词或字幕文字，作为声音内容的文字证据。
- 已配置支持图像输入的 AI 接口时，可分析最多 3 张作品封面中可见的**自述文字**；结果作为建议展示，不凭外貌、音色或画面人物推定账号主人性别。
- 面板显示建议、依据、哪些来源已分析以及局限；用户手动选择并保存本地性别标记后，才用于后续定向筛选。
- 修正登录态主页实测性别标签的 DOM 读取。

## 边界

- 本版不自动提取视频音轨、识别声线或转写音频。视频页使用媒体 URL/Blob，当前浏览器无可用音轨采集接口；若无可读字幕，音频仍需用户提供台词文字。
- 封面出现的人可能不是作者；作品可能是剧情、转发、配音。所有作品识别结果仅供人工核对，不直接触发自动私信。
- AI 未配置或图像模型不支持时，仅使用标题/文案及用户提供的台词文字。

## 验收

- 只采集当前达人主页作品列表，最多 6 条标题、3 张封面；作品不足时给出明确状态。
- 明确的男性或女性自述给出建议；冲突、仅出现第三人称或模糊内容保持未知。
- 点击分析不会写入达人库或发送私信；手动保存标记后才影响交友筛选。
- 类型检查、测试、构建通过；公开主页手动验证采集，AI 与登录态 IM 仍需用户环境验证。
