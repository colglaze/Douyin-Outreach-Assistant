# REQ-20260902-01 — MVP 需求与范围冻结（v0.1 ~ v0.3）

> 关联：PRD.md。本文档是 v1 之前的**范围冻结**，任何"顺手加的功能"都不得进入本次开发。

## 1. 背景

验证三个问题：有没有人需要？是否真的提高达人联系效率？抖音网页版 DOM 操作是否足够稳定？

## 2. 纳入范围（MVP 七件事）

| # | 功能 | 验收标准 |
|---|------|----------|
| 1 | 达人识别 | 打开 `/user/*` 主页后自动解析昵称、粉丝数、简介、secUid、主页链接 |
| 2 | 达人资料展示 | 悬浮面板展示当前达人资料（昵称/粉丝/标签/简介） |
| 3 | 达人收藏 | 一键加入本地达人库（IndexedDB），重复加入有提示 |
| 4 | 私信模板 | 内置模板 + `{{nickname}}` 等变量自动替换 |
| 5 | AI 润色 | 可选：配置 OpenAI 兼容接口后对模板内容个性化改写；未配置时静默降级 |
| 6 | 一键填入私信 | 点击后打开私信窗口并将文案写入输入框（不自动发送） |
| 7 | 联系记录 | 填入后自动保存 Message 记录并更新达人状态为 CONTACTED；再次访问显示防重复提醒 |

## 3. 明确不做（范围冻结）

- 自动筛选/翻页/批量采集达人
- 无人确认连续发送、自动点击发送按钮
- 复杂数据分析 / 仪表盘 / A/B 统计
- 多租户、付费、企业账号、云端同步
- Chrome Extension 迁移（属 V1.0，另行 REQ）
- 搜索页快捷收藏（V0.4+ 候选，先记录不实现）

## 4. 联系状态机

`NEW → SAVED → CONTACTED → REPLIED → INTERESTED → NEGOTIATING → COOPERATING → FINISHED`，另有 `REJECTED`。

## 5. 版本切片

- **V0.1**：达人识别 + 悬浮按钮 + 打开私信 + 填入测试文字（技术验证）
- **V0.2**：达人收藏 + IndexedDB + 私信模板 + 联系状态
- **V0.3**：AI 润色 + 达人标签 + 防重复联系（完整 MVP）
