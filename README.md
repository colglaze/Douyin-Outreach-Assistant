# 抖音达人商务助手 (Douyin Outreach Assistant) — 使用说明

Tampermonkey 用户脚本：在抖音网页版上辅助达人商务触达——识别达人资料、建立达人库、
私信模板一键填入、AI 润色、联系记录与防重复提醒。

## 一、安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Chrome/Edge 均可）。
2. 本地构建（仓库内执行一次）：
   ```bash
   npm install
   npm run build
   ```
   产出 `dist/douyin-outreach.user.js`。
3. 打开 Tampermonkey 管理面板 -> 「实用工具」-> 「导入文件」，选择
   `dist/douyin-outreach.user.js`；或新建脚本后把 dist 文件内容整体粘贴保存。
4. 确认脚本处于「已启用」状态，然后打开 [www.douyin.com](https://www.douyin.com/)。

> 改了代码后重新 `npm run build`，再在 Tampermonkey 中更新脚本内容即可。

## 二、日常使用流程

1. **识别**：打开任意达人主页（`/user/*`），页面右侧出现悬浮球（悬浮按钮）。
2. **打开面板**：点击悬浮球，面板展示该达人昵称、粉丝数、简介标签。
3. **加入达人库**：未入库的达人点击「加入达人库」，之后可用状态单管理联系进度
   （未联系 -> 已收藏 -> 已联系 -> …）。
4. **私信触达**：
   - 在面板选择「私信模板」（内置商务合作/产品置换，变量自动带入）；
   - 可点击「AI优化」润色话术（需先在设置中启用并填 Key）；
   - 点击「打开私信」拉起 IM 窗口，再点「填入私信」把内容写入输入框。
5. **发送**：
   - 默认：人工点击发送（推荐，第一条私信只有一次机会）；
   - 或在设置中开启「消息自动发送」，填入成功后脚本自动点击一次发送。
6. **防重复**：联系过的达人再次访问时面板顶部会出现黄色提醒（上次联系时间 + 状态）。

### 推荐页连刷自动化（V0.5.3，待真实环境复测）

在抖音**首页（推荐/精选）**打开面板，即显示「连刷自动化」视图：

1. 前置条件：**已登录** + 设置中已开启「消息自动发送」（否则启动会被拒绝）；
2. 建议在 ⚙ 设置 -> 连刷自动化 中先填好**自定义私信内容**
   （支持 `{{nickname}} {{brand}} {{wechat}}` 等变量，留空则使用默认模板），
   并确认「单会话发送上限」（默认 10 条）；
3. 点击「▶ 开始连刷」，脚本自动循环：进入推荐 feed -> 采集当前视频作者 ->
   进入达人主页 -> **跳过已联系达人** -> 填入私信 -> 自动发送（发送成功以输入框清空为准）
   -> 关闭私信面板 -> 返回推荐页 -> 连刷切换下一位继续；
4. 面板实时显示状态/已发送数/已访问数；随时可点「■ 停止连刷」；
   连续失败 2 次或达到上限会自动停止并提示原因。

> **过程中页面整页跳转是正常现象**：抖音进入达人主页必然整页刷新（平台行为），
> 连刷进度保存在当前标签页的 sessionStorage 中，页面重载后自动续跑；
> 点「停止」、达到上限、连续失败或关闭标签页后，进度即失效，下次需重新手动启动。
> 无人值守定时群发、跨浏览器会话自动恢复不在产品范围内。
>
> **平台限制**：对方回复或关注你之前，只能发送 1 条文字消息（抖音限制）。
> 因此对同一达人重复发送会被平台拦截，脚本会判为失败并计入连续失败，属预期行为。

## 三、设置（面板头部 ⚙）

| 分区 | 配置项 | 说明 |
|------|--------|------|
| 品牌信息 | 品牌名称/简介/产品/联系人/微信号/达人类型 | 模板变量 `{{brand}}` 等的数据来源，保存后立即生效 |
| 默认模板 | 下拉选择 | 面板打开时的初始模板 |
| AI 润色 | 启用开关/接口地址/API Key/模型/语气 | OpenAI 兼容接口；Key 仅存本地浏览器，未配置时自动降级为原文 |
| 消息自动发送 | 开/关 | **改动即时保存，无需点保存按钮**；连刷自动化依赖此开关 |
| 连刷自动化 | 自定义私信内容/单会话发送上限 | 文案支持模板变量，留空回退默认模板；上限默认 10 条 |

其余配置项（保存按钮）：品牌/模板/AI 表单填写后点「保存设置」。

### 消息自动发送开关

- **存储位置**：浏览器 IndexedDB（`douyin-outreach` 库 -> `settings` store，
  key `app`），与全部配置同一条记录。
- **生效范围**：全局持久——本浏览器所有达人页、所有模板生效，刷新页面后保持；
  不区分达人、不区分模板。
- **行为**：开启后，每次「填入私信」成功且联系记录落库后，自动点击**一次**发送，
  消息记录状态为 `SENT`；关闭时需人工点击发送（状态 `FILLED`）。
- **默认关闭**。无人值守的定时/跨会话自动启动不在产品范围内。

## 四、数据与隐私

- 达人库、联系记录、全部设置（含 API Key）**只存在本浏览器 IndexedDB**，不上传任何服务器。
- 换浏览器/清缓存 = 数据清空，如需迁移请自行导出 IndexedDB。

## 五、注意事项与已知边界

1. **自动化边界**：连刷自动化必须手动启动/停止、跳过已联系达人、有单会话上限；
   无人值守定时群发、验证码处理、风控绕过永远不会提供。
2. **看不到悬浮球？** 先确认 Tampermonkey 中脚本已更新到 **v0.5.3** 并启用、页面已刷新；
   若左下角出现红色"初始化失败"横幅，请截图反馈。
3. **抖音私信限制**：对方回复或关注你之前，**只能发送一条文字消息**，第一条话术
   质量极其关键，请善用 AI 润色并人工把关。
4. **登录要求**：私信相关功能（打开私信/填入/发送/连刷）需要登录态；达人识别与
   达人库匿名态也可用。
5. **抖音改版**：页面结构变化可能导致解析/按钮定位失效，选择器集中在
   `src/douyin/selectors.ts`，改版时只需校准该文件并重新构建。
6. AI 润色通过浏览器直连你填写的接口地址，接口需支持 CORS 或由 Tampermonkey 的
   `GM_xmlhttpRequest` 代理。
